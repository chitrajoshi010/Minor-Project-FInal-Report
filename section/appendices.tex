\section*{Appendix C: HARDWARE PROTOTYPE SETUP}
\addcontentsline{toc}{section}{Appendix C: HARDWARE PROTOTYPE SETUP}
\label{app:hardware_setup}

The hardware implementation details of the proposed forest monitoring sensor
node are presented in this appendix. The prototype consists of an ESP32-S3
microcontroller, MEMS microphone, temperature and humidity sensor, gas sensor,
and LoRa communication module.

The complete hardware connection diagram of the sensor node is shown in
Fig.~\ref{fig:hardware_setup}.
